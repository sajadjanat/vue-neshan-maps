# Vazir

Unmodified regular and bold WOFF2 files from `vazir-font@30.1.0` on the npm registry.
Upstream: https://github.com/rastikerdar/vazir-font

Copyright 2015 The Vazir Project Authors. Distributed under SIL OFL 1.1.
See `OFL.txt` and `AUTHORS.txt` for the original license and credits.

Import `vuejs-neshan-map-leaflet/fonts/vazir.css` and place the
`neshan-font-vazir` class on your map or its surrounding interface.
The stylesheet does not apply a global body font or modify map tile labels.
