# ‏دموی تعاملی

‏[اجرای دموی فارسی](https://sajadjanat.github.io/vue-neshan-maps/?lang=fa) · [English](DEMO.md) · [مرجع API](API.md)

‏دمو از کامپوننت‌های واقعی پکیج و نقشهٔ نشان استفاده می‌کند. زبان را هر زمان عوض کنید؛ نقشه و تنظیمات جاری حفظ می‌شوند. رابط فارسی و پنجره‌های HTML با فونت وزیر نمایش داده می‌شوند؛ نوشته‌های وکتور نقشه از فونتِ سبک نشان استفاده می‌کنند.

## ‏اتصال

1. ‏در [پنل نشان](https://platform.neshan.org/panel/api-key) یک **کلید وب** بسازید.
2. ‏دامنهٔ `sajadjanat.github.io` را برای کلید مجاز کنید و سرویس‌های نقشه، POI و ترافیک MapLibre را فعال کنید.
3. ‏کلید را در بخش «اتصال به نشان» وارد کنید و «نمایش نقشه» را بزنید.

‏کلید فقط در حافظهٔ همین صفحه می‌ماند؛ در مرورگر ذخیره نمی‌شود، داخل URL یا کد خروجی قرار نمی‌گیرد و به سرور دمو ارسال نمی‌شود. اتصال نشان آن را برای دریافت نقشه به خود نشان می‌فرستد. بارگذاری مجدد صفحه، کلید واردشده را پاک می‌کند. کلید سرویس برای نمایش نقشه کاربرد ندارد.

## ‏چه چیزهایی را امتحان کنیم؟

| بخش | امکانات قابل آزمایش |
| --- | --- |
| ‏نمای نقشه | ‏انتخاب موتور و سبک، ترافیک و POI، جابه‌جایی مارکر و پنجرهٔ مکان، انتخاب نقطه، اندازه‌گیری فاصله، بزرگ‌نمایی و نمایش مکان‌ها |
| ‏تحلیل داده | ‏۱۰۰ تا ۱۰هزار نقطهٔ نمونه، شعاع خوشه و بازشدن خودکار، دریافت نقاط داخل خوشه، هیت‌مپ هم‌زمان با خوشه‌ها، تنظیم شعاع/شدت/شفافیت و جایگزینی یا دانلود داده |
| ‏لایه‌ها | ‏خط چین، دایره با شعاع متری، چندضلعی، ارتفاع و شفافیت حجم سه‌بعدی، کلیک لایه و ویرایش GeoJSON |
| ‏کد و خطا | ‏کپی نمونهٔ Vue با تنظیمات جاری یا شروع Nuxt 4؛ شبیه‌سازی خطاهای کلید، سهمیه، نرخ درخواست، دامنه و مجوز؛ مشاهدهٔ خطاهای واقعی |
| ‏گزارش نقشه | ‏تعداد عارضه‌های نمایانِ ترافیک، POI و خوشه‌ها، منابع و لایه‌های موتور، رویدادهای اخیر |

‏دکمه‌های بالای نقشه چهار سناریوی «مکان‌ها»، «خوشه‌بندی»، «تراکم» و «سه‌بعدی» را فعال می‌کنند. پس از انتخاب سناریو، همهٔ تنظیمات قابل تغییرند. نمای بزرگ با کلید Escape بسته می‌شود. در موبایل، نقشه بالای ابزارها قرار می‌گیرد.

‏برای دریافت نقاط خوشه، در «تحلیل داده» بازشدن خودکار را خاموش کنید؛ روی یک خوشه کلیک و دکمهٔ دریافت نقاط را بزنید. با تغییر داده یا سبک، خوشه را دوباره انتخاب کنید.

‏ویرایشگر، Feature یا FeatureCollection تا یک مگابایت و ۱۰هزار عارضه را می‌پذیرد؛ URL دلخواه دریافت و متن عارضه اجرا نمی‌شود. ترتیب مختصات GeoJSON «طول، عرض» است؛ مختصات کامپوننت و نمایش زیر نقشه «عرض، طول» است.

‏شمارنده‌ها مربوط به نمای فعلی نقشه‌اند و کل داده‌ها را نمی‌شمارند. داده‌های نقاط و محدوده‌ها نمونه‌اند؛ نقشه و لایه‌های زنده از نشان می‌آیند. اندازه‌گیری، فاصلهٔ جغرافیایی قطعات مستقیم است و مسیر خیابانی محاسبه نمی‌کند. دکمهٔ موقعیت فقط پس از کلیک اجازهٔ مرورگر را درخواست می‌کند.

‏شبیه‌ساز خطا برچسب مشخص دارد، درخواست شبکه نمی‌فرستد و سهمیه مصرف نمی‌کند. خطاهای واقعی به کلید، مجوز حساب و شبکه بستگی دارند. Leaflet مارکر و هندسهٔ پایه را حفظ می‌کند؛ تحلیل پیشرفته و لایه‌های زنده به MapLibre نیاز دارند.

## ‏اجرا و انتشار

```bash
npm ci
npm run dev
npm run build:demo
```

‏گردش کار `Deploy interactive demo` خروجی `demo-dist` را روی GitHub Pages منتشر می‌کند. آدرس نسبی فایل‌ها، مسیر زیرپوشهٔ ریپو را پشتیبانی می‌کند. بیلد عمومی کلید حساب را به‌صورت پیش‌فرض ندارد. برای توسعهٔ محلی می‌توانید `VITE_NESHAN_WEB_KEY` را در فایل نادیده‌گرفته‌شدهٔ `.env.local` قرار دهید؛ کلید را کامیت نکنید. صفحهٔ npm و هر دو ریدمی به همین برنامهٔ آنلاین لینک دارند.
